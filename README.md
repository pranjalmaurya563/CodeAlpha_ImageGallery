A clean and modern **responsive image gallery** built using HTML, CSS and JavaScript as part of the **CodeAlpha Frontend Development Internship**.

This project focuses on creating an interactive gallery with category filters, image previews, smooth animations, and a responsive design for different screen sizes.

---

## 🚀 Features

* Category-based image filtering
* Full-screen lightbox image preview
* Next and Previous image navigation
* Keyboard navigation using Arrow Keys
* Close lightbox using Escape key
* Click outside image to close lightbox
* Smooth hover effects and transitions
* Interactive "View Image" overlay
* Modern dark-themed UI
* Responsive design for desktop, tablet and mobile
* Categories: Nature, Animals, Travel and City

---

## 🛠 Tech Stack

* HTML5
* CSS3
* JavaScript
